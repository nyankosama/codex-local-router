# LLM Auto Gateway 文档入口

这些文档是本项目后续实现、评审和验收的长期约束来源。它们描述稳定边界与判断原则，不替代具体实现设计。

## 文档结构

- [范围与决策](./scope.md)：第一版边界和技术方向。
- [架构与实现设计](./architecture.md)：模块、运行逻辑、配置、能力和安全规约。
- [多模型与历史恢复](./multimodel-history.md)：压缩职责、配置、持久化及管理命令。
- [测试与交付](./acceptance.md)：验收矩阵、测试分层和交付报告要求。
- [E2E 规范](./e2e/goal-spec.md)：E2E 验收执行规范、判据与 patch loop 契约。
- [E2E 绊线](./e2e/thresholds.json)：异常绊线唯一来源（改动属 B 类，须批准）。
- [E2E 验收记录](./e2e/acceptance.md)：本轮结论、归因、patch 记录与人工签核。
- [验收工具链（公开）](./public/acceptance.md)：随包发布的 `npm run e2e*` 使用说明。

## 解释优先级

1. 用户当前明确确认的产品边界。
2. 本目录中的规约文档。
3. 具体实现和测试中的细节。

实现遇到未明确的技术细节时，应遵循规约自行判断；只有会改变产品边界、凭证权限或验收标准的决策才需要升级确认。
